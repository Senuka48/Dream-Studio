Files:

- dream-studio-logo.png
- whatsapp-logo.png

Everything needed by the current HTML page is included in this folder.

TEST ON YOUR COMPUTER
1. Keep all three files in the same folder.
2. Double-click index.html.
3. The Dream Studios website should open in your browser.

FREE HOSTING WITH GITHUB PAGES
1. Create/sign in to a GitHub account.
2. Create a new repository, for example: dream-studios
3. Upload index.html, dream-studio-logo.png, and whatsapp-logo.png.
4. In the repository, open Settings > Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Select the main branch and the / (root) folder, then Save.
7. GitHub will provide your free github.io website address.

IMPORTANT
- Keep the filenames exactly the same because index.html references them directly.
- A custom .com address such as www.dreamstudio.com requires registering that domain. The hosting can still be free.
